## 2. 开房实测这 8 条（按易坏程度排序）

> 怎么开房：双击 `tests/启动多开.bat` → 建 4 人房 → 「开启作弊/调试模式」→ 开局。
> 战斗界面里按 **`3`** 可以给自己发「3 张同系斩 + 3 张异系法术」，按 **`2`** 发每个技能的技能牌，
> 大部分技能的前置条件靠这两个键就能凑出来。

### ① 带选项的技能（最容易坏）

- **灵熙之潮【海神御巫】4606**、**异教徒【天雷劫火】9507 /【地裂波涛】9508**
- 点技能栏里这个技能 → 应该弹出二级技能栏，一排选项按钮
- **看**：按钮底色对不对、文字有没有被截、鼠标指上去弹不弹说明
- **不对说明**：选项数据源串了 → 回退 `d8b2654`（客户端改读）或 `a2d8bb5`（服务端双写）

### ② 选项带牌白名单

- 同上，选「雷系 / 地系」那一档
- **看**：手牌里不是该系的牌应该**立刻变灰**
- **不对说明**：`_牌过选项牌系` 或牌白被读丢了 → 回退 `aa53b10`

### ③ 先弹选项置灰（我之前判错的那条）

- **百鬼夜行 1804**、**魔眼 2605**、**美杜莎之眼 3503**
- 进技能后**先别点效果**
- **看**：手牌应该**整片灰**；点完效果才亮
- **不对说明**：需牌清零那段被改坏 → 回退 `d7c0fe6`（拆分 `_进入技能询问`）
- 例外：**神官【神圣领域】1506** 配了「允许先选牌」，它**应该**先亮

### ④ 攻击结束二选一

- **剑之子【剑残影】10804 /【剑影断念】4504**
- 打出一张攻击牌 → 攻击结束后应该弹二选一
- **看**：两张选项各自的目标数、需牌数不同（剑残影 1 名目标、断念 0 名）
- **不对说明**：`option_need_targets` 串位 → 回退 `b09c33f`（选项读取表驱动）

### ⑤ 额外行动两份不串

- 连续拿两份【疾风技】101（或用能连发的技能）
- **看**：技能栏里出现两颗同名按钮；点第二颗时，**消耗的是它自己那份**，不是第一份
- **不对说明**：`uid` 认人坏了 → 本次没动这块逻辑，先看引擎 `额外行动按ID`；只有按钮外观问题才回退 `8096f60`

### ⑥ 二级栏「返回」

- 任意带选项的技能进去 → 点「返回」应该回到上一层
- **裁决者 3906** 这类「锁定不可取消」的技能：**「返回」和「取消」都该点不动**
- **不对说明**：返回按钮回调没接上 → 回退 `8096f60`（按钮收口把返回钮也换成了 `_造按钮`）

### ⑦ 特殊行动三种

- 技能栏最左【特殊行动】→ 购买 / 合成 / 提炼
- **看**：条件不满足的那几种是**半透明点不动**（不是消失）
- **不对说明**：按钮可用性判断 → 回退 `a3bd4ea` 或 `e528676`

### ⑧ 掉线重连

- 中途让一个窗口断网/最小化很久再回来（或直接关掉重开同一个槽位）
- **看**：服务端把「正等他的那份询问」补发回来，界面能正常显示并继续操作
- **不对说明**：大概率不是本次改动，先看 `_on_command` 的复位逻辑
