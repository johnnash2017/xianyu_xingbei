## 查看实时状态

```bash
python 项目文档/开发认领/claim.py status
```

记录目录：

- `claims/<任务>.json`：谁认领、认领时间、实现摘要、跑的测试、改动文件。
- `reviews/<任务>.json`：谁评审、通过/问题、评审时间。
- 被阻塞/退回的问题会写进 `tasks.json` 的 `issues`（已完成后移入 `history`）和对应 claim/review。
