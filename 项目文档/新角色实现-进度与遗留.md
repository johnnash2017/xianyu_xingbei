## 2. 逐角色修复明细

### 2.1 94 记录者（本轮重写 `role_jiluzhe.gd`）

修复：

1. **阻断**：`引稽编鉴` 的询问字符串引号未闭合（整个脚本加载不了）——随重写一并修掉。
2. **选项永远为空**：原代码在 `if 牌 == null: continue` 之后把 `选项.append(...)` 写在 if 块里（缩进错位），
   三处「选项列表」实际上永远是空的（9402 选牌、9404 档位都点不出来）。重写后选项在循环体里正常追加。
3. **知行合一 9402**：
   - 选牌与「弃 1 张手牌」合成**同一条询问**（约定 22），不再先选牌再单独弃牌；
   - 选中的牌加入手牌后给一份 `direct` 的「只能用这张牌」的额外行动（同 7803 / 9303 的写法），
     行动结算完成（`p_action_end` 的 `extra_cause == 9402`）才把剩余展示牌弃掉、+X【史料】；
   - 额外行动被放弃时在 `p_turn_end` 收尾：这张牌不算白拿，按技能口径弃掉（原来会白留一张）；
   - 取消 = 不把展示牌作为行动发出：两张都弃掉、+2【史料】（原来取消时两张牌凭空消失）。
4. **稽古识典 9403**：不再用「先压弃牌状态、再同步发史书」的写法；改为在当前流程里先问「弃 1 张牌」，
   拿到答复（或超时补手牌第一张）后再发【史书】，顺序与原文一致；【史书】从 `移除牌堆` 取回后再进手牌
   （约定 13，原来被【以史为镜】移出后就再也发不进来）。
5. **秘境万象 9406**：伤害目标数按 `min(X-3, 在场人数)` 取（约定 23），不再在 X 很大时卡到超时；
   取消/非法目标不再静默补人。
6. **古今互鉴 9408**：交换条件改为「手牌 ≥ 2」；`X` 与所选手牌张数、遗迹数一起校验；
   稽古识典的弃牌放在技能最后收尾，避免「+2 史料后多压一层状态把交换询问挤掉」。
7. **引稽编鉴 9409**：攻击目标交牌改用技能询问本人选（原来走 `RespondType.Discard` 再把手牌第一张
   当遗迹，弃牌日志和拦截钩子都跑错）；交换档位 1~2 与手牌张数一起校验；结算完继续走 9404。
8. **遗迹论破 9404**：从 `p_before_attack` 挪到 `p_timeline_1`（原文「主动攻击时①」）；标记在攻击开始时复位；
   与 9409 同一处 ① 时点串行（9409 先、9404 后），不再互相吞掉。
9. **传说之地 9401**：开局取牌改走 `engine.移除牌库顶`（会广播快照），仍然面朝上作为【遗迹】。

遗留 / 口径待确认：

- **9404 的 X 上限**：技能原文没有上限，`遗迹` 上限 8，但设计表「按钮」列只配了 1/2/3 三档，
  所以现在只能移除 1~3 个。要支持 X>3 需要设计表补「按钮4~8」后重新导表。
- **9407 以史为镜**：「转移拥有者 / 因技能放置在角色旁」两种情况没有落点——实际对局里【史书】只会
  留在记录者手上（9409 只交换手牌与遗迹、秘境万象直接移除），暂不实现。
- 9402 选到【圣光】这类只能响应的法术牌时，给出的额外行动点了会被驳回（引擎不接受主动施放【圣光】），
  玩家只能放弃；属于规则边缘，暂不特判。

### 2.2 80 神秘学者（本轮重写 `role_shenmixuezhe.gd`）

修复：

1. **选项永远为空**：原 `_真言术` 把 `选项.append(...)` 写在 `if 牌 == null: continue` 的块里（缩进错位），
   真言术的言灵选项实际是空列表，技能点了也选不出言灵。重写后正常下发选项（带 `card_id`，客户端可摊卡面）。
2. **8001 只能放 1 张【言灵】**：`available_skills` 补 `card_max = 2`，服务端校验 1~2 张；
   【言灵】上限改读角色表盖牌槽（`player.cover_space()`），不再写死 3。
3. **8001 摸牌后接续**：摸 1 张改走 `push_强制摸牌` + `URGENT`，覆写 `技能URGENT后重入`（只放行 8001 的
   「摸完等额外弃牌」这一步），摸牌超限弃牌结算完再问「额外弃 1 张同系牌」；同系白名单同时用于询问与校验
   （原来白名单为空＝任意牌都能弃）。
4. **8003 的 1 点法术伤害永远不结算**：`_真言待伤` 原来在发问前就被清掉，答复回来条件已不成立。
   现在标记留到取到答复之后清，并在 `p_action_end`（额外行动结束）里发问、压伤害。
5. **8003「或你额外移除 1 点【秘术】」**：不是咏类 / 法术牌时，若有【秘术】就多问一次「是否额外移除 1 点【秘术】」，
   确认后扣 1 点并让本次行动结束后的 1 点伤害生效（原来 `_真言阶段 = 2` 是死状态）。
6. **8003 打出去的牌不白留**：给出的行动没用掉时，回合结束把那张牌放回【言灵】区（`p_turn_end`）。
7. **8006 真言压制**：目标从「敌人」改为「场上任意角色」（术语表：目标角色）；
   「你可立即执行一次【真言术】」实现为一份只放行 8003 的立刻法术行动（`_真言压制重真言`），
   `available_skills` 在该窗口只摆真言术、`v_magic_skill` 也只接受 8003。
8. **8005 妖精秘术**：触发条件补上「【真言压制】结算后」；命中加【秘术】走 `p_timeline_2_hit` 的本次攻击标记。
9. **8002 守护灵**：拆哪个【言灵】、补哪张手牌都改由玩家一次选完（`HandOrCover` + `cover_need=1/hand_need=1`），
   不再由服务端取 `cover_cards[0]` / `hand_cards[0]`；补进去的牌补上 `Card.Show` 展示。
10. **8004 禁忌秘法**：两名目标各自由本人选牌弃掉（`RespondType.Discard`，超时按手牌顺序补一张），
    弃牌进弃牌堆后再从弃牌堆取回、面朝上作为【言灵】（约定 12 的「先弃置再取回」）。

遗留 / 口径待确认：

- 8004 的弃牌若被「弃牌前拦截」认领（如噬神者【渗蚀】），取不回弃牌堆里那张，就少一个【言灵】（不再重复造牌）。
- 8003 选到【圣光】这类只能响应的法术牌时，给出的行动点了会被驳回，玩家只能放弃；规则边缘，暂不特判。

### 2.3 81 女仆长

修复：

1. **8102 / 8103 时点错位**：两条都从 `p_after_attack`（整次攻击结算完）挪到
   `p_timeline_2_hit` / `p_timeline_2_miss`（原文「命中 / 未命中时②」），
   并把原来「发问前先清 `_本次命中` → 答复永远不被读取」的写法改成「阶段标记，取到答复后才清」。
2. **8107 影之风**：命中后把进弃牌堆的攻击牌自动变【影】的逻辑也随 8102 一并挪到 ② 时点；
   「每次【攻击行动】结束 +1【糸】」留在 `p_after_attack`。
3. **8105 侍奉之道**：非同系时两张【影】原来移除后没有去处（牌凭空消失），现在进弃牌堆；
   同系时「把其中 1 张交给目标角色」改成由玩家一次选完（选项＝交哪张影，目标＝任意角色），
   取消则两张都进弃牌堆；只有同系那一路才【横置】。
4. **8109 风止**：弃 2 张作【影】前先看盖牌槽余量，放不下的牌进弃牌堆（原来装满后再放置会立刻触发盖牌超限）。
5. **回合结束的顺序**：`_风止已处理` 标记，修掉「侍奉之道等回复后重入回合结束钩子、又重问一次风止」。

遗留 / 口径待确认：

- 8104 / 8105 的「从弃牌堆取回 1 张作影」如果被「弃牌前拦截」认领，就取不回那张（不再重复造牌）。
- 8106 的【重置】目前要求「已【横置】且【糸】≥3」才询问，与原文「若你已横置，额外移除 3 点【糸】」一致。

### 2.4 83 染污者

修复：

1. **8306 扭曲之爱 / 8303 狂戾之心 弃牌没离手**：两处都只调了 `to_discard`、没 `take_from_hand`，
   牌会「复制」——手牌不减、弃牌堆多一张、同一张可以反复弃。现在选牌 → `take_from_hand` → `to_discard` → 写弃牌日志。
2. **8301 神弃之裔「治疗上限 0【恒定】」**：原来只写 `cross_max = 0`，别人用「突破上限」类技能
   （神圣契约 / 圣光祈愈）仍能给他加治疗。新增角色钩子 `BattleRole.禁止获得治疗()`，
   引擎 `add_cross` / `add_cross_pierce` 都会问它，染污者恒返回 true。
3. **8303 狂戾之心**：空手时不再白发一次「弃 1 张牌」询问（等到有牌再触发）；变身询问改成不可取消
   （原文是「……时」的强制口径），`step` 改成阶段标记（发问前不再提前把进度写死）。
4. **8305 神智污染**的「无法用【治疗】抵御」沿用 `harm["cross_available"] = 0`（引擎 SAskCross 会读）。

遗留 / 口径待确认：

- 8306 的两问（形态+弃/摸 → 戾气数）保留：组合数是 4×3，塞一条询问会糊成一片；第一问的弃牌已当场结算。
