# 多开测试说明（F9 / F10 / F11）

在单机上一次拉起多个客户端窗口，快速验证联机。全部逻辑在本目录的 `启动多开.ps1`。

> 本项目总入口见 [README](../README.md)（含运行模式、导表工作流、作弊模式等）。

## 一、前提

- 装好 Godot 4.7（编辑器即可，路径不限；版本与工程一致）。
- 能打开本工程（`xianyu_xingbei`）。

## 二、怎么启动

- 最省事：双击本目录的 **`启动多开.bat`**（默认 4 开，不自动开局）。
- 命令行：

  ```powershell
  powershell -ExecutionPolicy Bypass -File tests\启动多开.ps1 -Count 6 -Auto
  ```

- 常用参数：
  - `-Count N` 窗口数（1~8）
  - `-Width W` 固定窗口宽度（0＝等比铺满）
  - `-Names 甲,乙,丙` 批量起昵称（已有配置不覆盖）
  - `-Auto` 自动开局（进游戏后自动建房/进房/准备）
  - `-DryRun` 只演算不启动（预演）
  - `-KeepConsole` 保留脚本控制台（排查用）
- 反复运行会先关掉上一批（只认带 `--slot=` 的本工程进程），不会越开越多。

## 三、引擎找不到时

脚本按序自动探测 Godot 可执行文件：

1. 显式 `-EnginePath`
2. 工程/工作区的 `.vscode\settings.json`（`godotTools.editorPath.godot4`）
3. 工程同级或 `tools\` 下的 `godot*.exe`
4. PATH 里的 `godot4` / `godot`
5. 常见 Steam 安装路径

都找不到就显式指定：

```powershell
... -EnginePath "D:\你的\Godot\godot.exe"
```

## 四、绑 F9 / F10 / F11（可选）

快捷键本身不随工程走，每人自己绑一次即可。作者惯用的三种绑法（与 [README](../README.md) 一致）：

| 快捷键 | “目标”末尾追加的参数 | 效果 |
| --- | --- | --- |
| F9 | 无 | 4 开，不自动开局 |
| F10 | `-Auto` | 4 开，自动建房 / 进房 / 准备 |
| F11 | `-Count 6 -Auto` | 6 开，自动进入六人房 |

绑法：

1. 右键 `启动多开.bat` → 发送到 → 桌面快捷方式；
2. 右键该快捷方式 → 属性 → “快捷方式”选项卡 → “快捷键”栏按 `F9`（或 `F10` / `F11`）；
3. 在“目标”末尾按上表追加参数，例如：`"...\启动多开.bat" -Count 6 -Auto`。

## 五、说明

- 这批窗口走**本地房间**（本机 TCP），不连 Steam。
- 窗口摆位按屏幕宫格自动排布（参数写在 `%APPDATA%\Godot\app_userdata\星杯传说\`）。
